# Artwork and font provenance

The source code and original project artwork use the repository's [MIT License](../LICENSE). This includes the restored candy cursor, for which the project owner confirmed redistribution rights and requested MIT licensing on 2026-10-14. Typography uses Anonymous Pro under the SIL Open Font License; its notice is bundled at `macos/Fonts/OFL.txt`. The generation record and source sheets are in [`art/GENERATED_ASSETS.md`](../art/GENERATED_ASSETS.md).

| Materials | Origin and use |
| --- | --- |
| `macos/Stickers/` and `macos/Stickers/Objects/` | 52 independent transparent cutouts packaged from four newly generated sheets |
| `macos/Wallpaper/pumpkin-field.png` | Newly generated original twilight pumpkin garden |
| `macos/CandyCursor.png` and `safari-extension/candy-cursor.png` | Restored user-supplied pixel-art candy; the project owner confirmed distribution rights and MIT licensing |
| `macos/FolderStyles/` | Six newly generated original folder designs |
| `macos/WebDecor/`, app icon, loading bat | Original drawn web and vector loader bat; newly generated bat app icon |
| `macos/PreviewScene/` | Local exports of macOS wallpaper and system icons used only while generating previews; ignored by Git |
| `macos/Previews/`, `docs/media/`, `docs/mac-app-window.png` | Product previews regenerated after the original art replacement |

The generated artwork uses prompts that ask for new compositions. Generation records support provenance but are not a legal warranty. The restored candy came from a user-supplied image, and the owner's rights confirmation applies to that file. Apple system UI shown in product demonstrations is illustrative; exported system assets are not included in the repository.

On 2026-10-14, the 22 uploaded Mac and Safari ZIPs were removed from all 11 historical GitHub releases through `v0.4.2`. The release pages, tags, and GitHub's automatic source archives remain. Those source archives and prior commits can still contain earlier artwork; replacing the working files does not rewrite Git history.
