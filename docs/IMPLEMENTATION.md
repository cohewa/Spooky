# Implementation notes

The five independent setting keys are `webs`, `stickers`, `folders`, `wallpaper`, and `cursor`. The native Mac window is the source of truth. Its five rows have compact, silent looping MP4 previews and custom glossy orange switches in a scrollable dark panel. The window bundles and registers Anonymous Pro for its labels; an animated bat indicator appears while applying changes. The pumpkin status item reopens the window. The wallpaper uses static bundled pumpkin-field artwork. The app exposes a read-only JSON snapshot over loopback for the temporary Safari extension, which updates visible pages by polling.

The `webs` switch creates a transparent, click-through window on every screen at the status-bar level, above the menu bar and ordinary app windows. The four reference spiders remain at their current size in the center; symmetrical web-only panels extend to both sides and rise into the top edge. The full composition is pinned to the physical top edge of the display. Transparent padding is cropped from the central artwork so no visible gap remains. The previous corner web, pumpkin garland, and flying bats have been removed. Safari no longer draws duplicate webs.

Wallpaper also enables autumn widget borders. The app reads window geometry from Core Graphics, identifies desktop widget windows by the Notification Center process bundle ID and desktop window level, and adds transparent decorations above each widget. It refreshes geometry once per second, removes borders when widgets disappear, and turns the overlay off with Wallpaper. Webs sit flush against varied widget corners. A twig garland runs along each top edge, with leaves and pinecones hanging from stems; the natural cutouts come from the existing sticker assets. The overlay ignores mouse events and stays below ordinary app windows.

The pumpkin is a native status item. On displays with a notch, macOS may place it outside the visible right menu bar area as other status items appear. Spooky checks the status button frame against the screen's auxiliary top-right area and shows a small clickable pumpkin panel inside that safe area only while the native item is obscured.

The six folder styles are maple, pumpkin, knit, stripes, bat, and kitten with pumpkin. Existing folders that had the removed skeleton style migrate to the pumpkin-only design. Icons are cropped to visible pixels and fitted proportionally to avoid transparent padding making some designs look truncated or undersized.

The cursor switch creates a transparent, click-through panel at the cursor window level. It polls the pointer position and draws the supplied pixel-art candy over the rest of the Mac; Core Graphics hides the native pointer while the effect is active and reapplies the hide when apps activate. Safari pages receive the same transparent PNG from the extension and hide the browser cursor on all elements, including editable fields. macOS may restrict native cursor hiding while Spooky is not the foreground app, depending on the system version.

The desktop implementation uses public AppKit APIs: NSWindow for the selection window and movable stickers, NSWorkspace for Desktop folder icons and wallpaper, and NSStatusItem for the pumpkin menu-bar shortcut. If a wallpaper's original file has been removed, Spooky first looks for macOS's matching rendered wallpaper cache and saves a restorable copy. AVFoundation plays the five bundled previews. Folder icons use six bundled designs; the app stores a random style assignment per folder in `folder-styles.json` so its 20-second scan does not reshuffle icons. It crops transparent source padding and fits visible artwork proportionally into a 512px canvas. Before changing each folder icon, it saves the original icon for restoration.

The temporary Safari installation and local HTTP bridge are a development path. A packaged Safari Web Extension would use native messaging and app groups as described in Apple's Safari documentation. It requires a full Xcode installation, currently absent from this Mac.

`demo/index.html` is a local visual preview with simulated settings. It does not verify Safari extension loading or native messaging.

On October 12, 2026, the Safari extension was confirmed on `example.com`: Web Inspector showed the injected root, custom cursor layer, and `cursor: none` on both the document and body. The local test page showed the pumpkin cursor. The five effect settings remained enabled as previously selected through the app restart.
