# Implementation notes

The six independent setting keys are `webs`, `skeletons`, `stickers`, `folders`, `wallpaper`, and `cursor`. The native Mac window is the source of truth. Its six cards have bundled, silent looping MP4 previews and native switches; an icon-matched bat indicator animates while applying changes; clicking a card or switch applies its effect. The pumpkin status item reopens the window. The app exposes a read-only JSON snapshot over loopback for the temporary Safari extension, which updates visible pages by polling. This bridge contains no page content and accepts no configuration writes.

The `webs` switch creates transparent, click-through windows on every screen, above ordinary app windows and across Spaces. Artwork for the white left web, dangling spider, right garland and flying bats is extracted from the supplied references. The spider descends and garland sways once per minute; bats fly immediately when enabled and then once per hour. Reduce Motion suppresses these animations. Safari no longer draws duplicate webs.

The desktop implementation uses public AppKit APIs: NSWindow for the selection window and movable stickers, NSWorkspace for Desktop folder icons and wallpaper, and NSStatusItem for the pumpkin shortcut. AVFoundation plays the six bundled previews. Folder icons use seven bundled original designs; the app stores a random style assignment per folder in `folder-styles.json` so its 20-second scan does not reshuffle icons. It draws each image into a 512px canvas with a 24px inset while preserving the artwork's aspect ratio, so wide folder designs such as the knit style stay fully visible in Finder. Before changing each folder icon, it saves the original icon for restoration. Before changing wallpaper, the app stores both the source URL and a local copy of the image; the copy can restore its pixels if the source file later disappears. The Safari content script creates one click-through overlay on each ordinary web page. It respects `prefers-reduced-motion`.

The temporary Safari installation and local HTTP bridge are a development path. A packaged Safari Web Extension would use native messaging and app groups as described in Apple's Safari documentation. It requires a full Xcode installation, currently absent from this Mac.

`demo/index.html` is a local visual preview with simulated settings. It does not verify Safari extension loading or native messaging.

On October 11, 2026, the temporary extension was loaded in Safari 26.6.2 and granted one-day access to the local test host `127.0.0.1`. `demo/live.html` contains no decoration script. On that page, webs appeared and disappeared when the app setting changed. Safari Web Inspector confirmed the Halloween cursor CSS on the page and `cursor: text` on the input. A temporary diagnostic counter confirmed a falling-skeleton burst with two skeletons while motion reduction was off and the page was visible. The diagnostic code was removed afterward. The new native window was opened, its web card was toggled on and off, stickers were toggled repeatedly, six Desktop folder icons were changed and restored, and wallpaper was changed and restored to its prior image. The original wallpaper source was initially missing; the same image was downloaded again from its source, restored, and the app was changed to preserve a local copy before future replacements.
