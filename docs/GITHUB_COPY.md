## Public announcement

> Meet Spooky, a small Halloween layer for your Mac. Turn on animated spider webs, place 52 movable desktop stickers, decorate folders, switch to an illustrated pumpkin wallpaper, and follow your pointer with a candy. Each effect has its own switch. The signed and notarized Mac app is available on the [0.5.24 release page](https://github.com/cohewa/Spooky/releases/tag/v0.5.24). Source code and project artwork are MIT-licensed; Anonymous Pro retains its font license.

## Binary release

**Title:** Spooky 0.5.24 for macOS

> Spooky adds five optional Halloween effects to your Mac. This release includes an illustrated pumpkin wallpaper, 52 movable desktop stickers, six folder styles, a screen-top spider web, and a candy pointer. Switch each effect off to restore the previously recorded desktop state.
>
> Download the notarized app archive below, unzip it, and move Spooky to Applications. The Safari Web Extension is not included; it remains a development-only component. Read the privacy and restoration notes before enabling wallpaper or folder icons. SHA-256: see the checksum file attached to this release.

The release archive was accepted by Apple notarization and passed local Gatekeeper assessment after extraction. A second-Mac installation check remains a follow-up for this release.
