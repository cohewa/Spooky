## First public source announcement

> Meet Spooky, a small Halloween layer for your Mac. Turn on animated spider webs, place 52 movable desktop stickers, decorate folders, switch to an illustrated pumpkin wallpaper, and follow your pointer with a candy. Each effect has its own switch. Source code and project artwork are MIT-licensed; Anonymous Pro retains its font license. The repository includes animated previews, build steps, privacy notes, and a release checklist. A signed and notarized installer will follow after Apple distribution setup and checks.
