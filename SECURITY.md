# Security policy

Spooky is in local development and does not yet offer a signed public binary. Please do not post a vulnerability, a private path, or a token in a public GitHub issue. Use GitHub's private vulnerability reporting or a private Security Advisory for this repository when available.

The app changes Desktop folder icons and wallpaper only when their switches are enabled. It stores local backups for restoration. The optional Safari extension has all-site access for cursor drawing and reads only the cursor setting from a loopback-only service.

For general bugs that do not expose sensitive information, open a GitHub issue with the macOS and Safari versions, the enabled effects, steps to reproduce, and a screenshot with personal content removed.
